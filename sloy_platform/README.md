### Шаг 1: Запуск Бэкенда (Сервера)
Бэкенд отвечает за базу данных, авторизацию, сохранение постов и работу чатов (WebSockets).

1. Откройте терминал.
2. Перейдите в папку с проектом:
   ```
   cd /Users/gatee/Desktop/123/sloy_platform
   ```
3. Создайте и активируйте виртуальное окружение (рекомендуется):
   ```
   python3 -m venv venv
   source venv/bin/activate
   ```
4. Установите все необходимые зависимости:
   ```
   pip install -r requirements.txt
   ```
5. Перейдите в папку бэкенда и запустите сервер:
   ```
   cd backend
   uvicorn main:app --reload
   ```
Если всё прошло успешно, вы увидите сообщение "Application startup complete". Сервер будет работать по адресу http://localhost:8000.

### Шаг 2: Запуск Фронтенда (Клиента)
Фронтенд состоит из статических HTML/CSS/JS файлов. Из-за того, что мы используем модули и динамическую подгрузку страниц (fetch), просто двойным кликом открыть index.html может не сработать (из-за политики безопасности браузеров CORS). Нужно запустить локальный веб-сервер для статики.

1. Откройте новую вкладку или новое окно терминала (оставив первую вкладку с работающим uvicorn открытой).
2. Перейдите в корень проекта:
   ```
   cd /Users/gatee/Desktop/123/sloy_platform
   ```
3. Запустите простой встроенный сервер Python:
   ```
   python3 -m http.server 3000
   ```
### Шаг 3: Откройте в браузере
Теперь, когда оба сервера работают:

1. Откройте ваш любимый браузер (Chrome, Safari, Firefox).
2. Перейдите по адресу: http://localhost:3000

### Как проверить, что всё работает правильно?
1. Регистрация: На открывшейся странице авторизации нажмите "Зарегистрироваться" (ссылка внизу), введите придуманный логин, почту и пароль.
2. API: Если вы вошли и вас перекинуло в Ленту, значит фронтенд успешно подключился к базе данных.
3. Загрузка медиа: Попробуйте создать пост и прикрепить к нему картинку. Если картинка появилась в ленте — сохранение файлов работает.

Если захотите остановить серверы, просто нажмите Ctrl+C в соответствующих окнах терминала.
